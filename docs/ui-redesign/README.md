# إعادة تصميم واجهة «الاول برو»

نقل الواجهة إلى Bootstrap 5 مع دعم كامل للعربية (RTL)، وهوية موحدة، وتنقل أسرع للمحاسب والكاشير على الكمبيوتر والتابلت والجوال.

- **الحالة:** P0 وP1 مكتملتان. P2 (المنصة) وP3 (الكاشير) منفَّذتان على الفرع التطويري وبانتظار مراجعة المالك قبل أي دمج.

## المراحل

| المرحلة | المحتوى | بوابة القبول |
|---|---|---|
| **P0** تمهيد | خط أساس للاختبارات والجودة والواجهة، وأداة الفحص، والوثائق | هذه الوثائق، و`git diff` فارغ على `app/` و`public/` |
| **P1** نظام التصميم والنموذج | ألوان وخطوط ومكوّنات وهيكل القائمة الجانبية، ونموذج HTML تفاعلي لخمس شاشات بـRTL وLTR على ثلاثة أحجام | موافقة المالك قبل أي كود في التطبيق |
| **P2** المنصة (M1) | Bootstrap 5 وRTL والخط ووسم `viewport` والقائمة الجانبية، وتحويل آلي لفئات BS3، واستبدال الإضافات، وصفحة الدخول | كل الشاشات تعمل بلا أخطاء، `dir=rtl` للعربية، ولا تمرير أفقي، وCI أخضر |
| **P3** الكاشير | المبيعات والاستلام والإيصال: لوحتان على الكمبيوتر والتابلت، وشريط إجمالي ثابت على الجوال، واختصارات ظاهرة | إتمام عملية بيع كاملة على الأحجام الثلاثة |
| **P4** المستندات | mPDF، وقوالب الفاتورة وعرض السعر وأمر العمل والفاتورة الضريبية بـRTL، وإيصال حراري 80 و58mm، وقوالب البريد | PDF عربي سليم لكل مستند |
| **P5** وحدات البيانات | الأصناف والعملاء والموردون والمجموعات والبطاقات والمصاريف والصندوق والموظفون والميزات والضرائب بنمط موحد | قائمة ونموذج لكل وحدة بلا فئات BS3 |
| **P6** التقارير | لوحة بداية بمؤشرات، وفهرس تقارير موحد، وChart.js | كل التقارير تعمل وتُرسم |
| **P7** الإعدادات والتجويد | تجميع تبويبات الإعدادات، وإتاحة الوصول، وتدقيق النصوص والمصطلحات، وحذف بقايا BS3 وgulp | بوابة BS3 تصل إلى صفر، وانتهاكات axe أقل من الأساس |

## قواعد العمل

- يُحقَّق من كل مرحلة بالفحص الآلي (`tools/ui-smoke`) على اللغتين والأحجام الثلاثة، وبـPHPUnit، وبفحص الأسلوب على الملفات المعدَّلة فقط (فالمشروع فيه مخالفات مسبقة، انظر `baseline.md`).
- كل نص جديد يظهر للمستخدم يُضاف إلى كل `app/Language/*` بترتيب أبجدي، وبقيمة فارغة حيث لا ترجمة، وفق `AGENTS.md`.
- لا تُضاف تعليقات تشرح الواضح، والأسماء بـcamelCase وPSR-12 كما في `AGENTS.md`.
- الالتزامات بصيغة `type(scope): subject` كما في تاريخ المشروع.
