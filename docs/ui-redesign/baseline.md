## 6. حقائق الاستضافة

**ما أفاد به المالك:** الاستضافة على Hostinger، مربوطة بالمستودع وتُحدَّث تلقائيًا، ومجلد `public/resources` رُفع يدويًا. أفاد الدعم الفني بوجود مشكلة عامة في الاستضافة.

**ما تحققت منه عبر موصل Hostinger:** حسابك فيه خادم VPS واحد (خطة KVM 1، نظام Ubuntu 24.04 LTS، الاسم `srv1966129.hstgr.cloud`، يعمل). لا أعرف إن كان هو من يستضيف الموقع.

**غير متحقق منه:** فرع النشر والمجلد، وإصدار PHP والإضافات، وجذر المستند، ووجود نطاق تجريبي، وهل الموقع على استضافة ويب أم على الـVPS.
- واجهات الاستضافة والنطاقات والفواتير وGit في Hostinger رجعت **HTTP 500** في كل المحاولات (آخرها بمعرف تتبع `a306a408-348b-49f2-ae4a-8b229098bf83`).
- رفض المالك طلب قراءة مشاريع Docker على الـVPS، فلم يُنفَّذ.
- النطاق `alawalpro.online` لا يُحَلّ من بيئة التطوير، فلم يُقَس الموقع الحي.

تُستكمل هذه الحقائق قبل أول نشر (M1)، من لوحة الاستضافة أو بعد عودة الموصل.

## 7. إعادة القياس

```sh
cd tools/ui-smoke
npm install
npm run gates
npm run smoke -- --compare baseline.json --fail-on-regression
```

الملف `tools/ui-smoke/baseline.json` يحمل أرقام الفحص الآلي أعلاه لكل شاشة ولغة وحجم.
