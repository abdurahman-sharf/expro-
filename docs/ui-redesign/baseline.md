## 6. حقائق الاستضافة

**ما أفاد به المالك:** الاستضافة على Hostinger، مربوطة بالمستودع وتُحدَّث تلقائيًا، ومجلد `public/resources` رُفع يدويًا. أفاد الدعم الفني بوجود مشكلة عامة في الاستضافة.

**ما تحققت منه عبر موصل Hostinger:** حسابك فيه خادم VPS واحد (خطة KVM 1، نظام Ubuntu 24.04 LTS، الاسم `srv1966129.hstgr.cloud`، يعمل). لا أعرف إن كان هو من يستضيف الموقع.

**تحققت منه عبر واجهة Hostinger (قراءة فقط، 2026-10-20):** الموقع `alawalpro.online` استضافة ويب (نطاق إضافي `addon`، النوع `other`) في حساب واحد يضم 17 موقعًا، والمجلد `domains/alawalpro.online/public_html`. بقية المواقع في الحساب لا علاقة لها بالمشروع ولم تُمَس.

| البند | القيمة |

| النشر التلقائي من Git | مفعّل: المستودع `abdurahman-sharf/expro-`، الفرع **`master`**، المجلد الجذر (فارغ). الفرع التطويري لا ينشر شيئًا |
| PHP | 8.3.35 (المشروع يتطلب 8.2 فأكثر) |

## 7. إعادة القياس

```sh
cd tools/ui-smoke
npm install
npm run gates
npm run smoke -- --compare baseline.json --fail-on-regression
```

الملف `tools/ui-smoke/baseline.json` يحمل أرقام الفحص الآلي أعلاه لكل شاشة ولغة وحجم.
