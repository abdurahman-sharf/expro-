# تفكيك النظام المرجعي (Daftra) — مرجع وظيفي

> **ما هذه الوثيقة:** وصف *وظيفي* لما يفعله النظام المرجعي، استُخلص بتصفح حساب العرض (`opes`) كمستخدم عادي **للقراءة فقط**: لم يُحفظ أو يُعدَّل أو يُحذف أي سجل. هي مرجع متطلبات، وليست نسخًا: لا شيفرة ولا قوالب ولا نصوص واجهة ولا صور تُنقل إلى المشروع، ولا تُحفظ بيانات الدخول في أي ملف.
>
> **حدود الاستكشاف:** الحساب فارغ تقريبًا (خزينة رئيسية واحدة برصيد صفر، لا فواتير ولا قيود)، فما يلي هو *هيكل* النظام وإعداداته وحقول نماذجه، لا سلوك الأرقام الفعلي. ما لم أرَه بنفسي لا أدّعيه (مذكور في آخر الوثيقة).

## 1. خريطة الوحدات

| الوحدة | الشاشات |
|---|---|
| **المبيعات** | الفواتير، عروض الأسعار، الإشعارات الدائنة، الفواتير المرتجعة، الفواتير الدورية، مدفوعات العملاء، إعدادات المبيعات |
| **العملاء** | قائمة العملاء، قائمة الاتصال، إعدادات العميل |
| **المخزون** | المنتجات والخدمات، الأذون المخزنية (إضافة/صرف/تحويل)، قوائم الأسعار، المستودعات، الجرد، الإعدادات |
| **المشتريات** | فواتير الشراء، مرتجعات المشتريات، الإشعارات المدينة، الموردون، مدفوعات الموردين، الإعدادات |
| **المالية** | المصروفات، سندات القبض (الإيرادات)، الخزائن والحسابات البنكية، إعدادات المالية |
| **الحسابات العامة** | القيود اليومية، دليل الحسابات، مراكز التكلفة، الأصول، إعدادات الحسابات العامة |
| **الموظفون** | الموظفون، أدوار الموظفين (صلاحيات), الإعدادات |
| **التقارير** | مبيعات، مشتريات، حسابات عامة، عملاء، مخزون |
| **القوالب** | قوالب الطباعة، قوالب الفواتير، قوالب البريد، الشروط والأحكام، المستندات، قواعد الإرسال الآلي |
| **الإعدادات** | معلومات الحساب، SMTP، طرق الدفع، **الترقيم المتسلسل**، **الضرائب**، الشعار والألوان، مفاتيح API |
| **أخرى** | مدير التطبيقات (إضافات)، سجل النشاطات، ربط الفاتورة الإلكترونية (هيئة الزكاة والضريبة والجمارك، المرحلة الثانية) |

الفكرة الحاكمة: **كل وحدة تشغيلية تُنتج قيدًا يوميًا آليًا**، والقيود اليدوية وجه واحد فقط من وجوه دفتر اليومية.

## 2. النواة المحاسبية

### 2.1 دليل الحسابات
- شجرة هرمية بخمسة جذور ثابتة، لكل جذر طبيعة رصيد:

| الرمز | الجذر | الطبيعة | الأبناء الافتراضيون |
|---|---|---|---|
| 1 | الأصول | مدين | 11 أصول ثابتة، 12 أصول متداولة |
| 2 | الخصوم | دائن | 21 خصوم متداولة، 22 خصوم طويلة الأجل |
| 3 | رأس المال وحقوق الملكية | دائن | 31 رأس المال، 32 أرباح وخسائر مرحّلة |
| 4 | الإيرادات | دائن | 41 إيرادات المبيعات، 42 إيرادات أخرى |
| 5 | المصروفات | مدين | 51 تكلفة المبيعات، 52 مصروفات إدارية وعمومية، 53 مصروفات الإهلاك، 54 مصروفات أخرى |

- التفاصيل تُنشأ تحت هذه المستويات (رأيت أرقامًا مثل 411 «المبيعات» و412 «مردودات المبيعات» و511 «تكلفة المبيعات» في صفحة التوجيه، فتُنشأ تلقائيًا عند الحاجة).
- كل حساب: رمز، اسم، رصيد معروض، وإجراءات **تعديل / إخفاء / تعليق**، وبحث، وإضافة حساب فرعي. لا حذف: الإخفاء والتعليق بدله.

### 2.2 القيد اليومي
- **المصدر (entity_type)** يربط القيد بمستنده. القيم التي رأيتها في المرشّح: يدوي، فاتورة، إذن مخزني، حركة مخزون، مدفوعات الفواتير، سندات القبض، تكلفة مبيعات الفواتير، فاتورة مرتجعة، مصروف، مرتجع مشتريات، **عمليات الأصل** (إنشاء/إهلاك/شطب/إعادة تقدير/بيع)، تحويل خزينة، إشعار دائن، مسير الراتب، **دورة حياة الشيك** (استلام/إيداع/تحصيل/رفض، مستلم ومدفوع)، تكلفة المنتج، طلب التصنيع، دفع فاتورة الشراء، فاتورة شراء.
- **حقول الرأس:** التاريخ، العملة (افتراضيًا ريال سعودي، مع «متعدد»)، الرقم، الوصف، مرفقات.
- **حقول السطر:** الحساب (إلزامي)، الوصف، مركز التكلفة، الضريبة، مدين، دائن؛ ومجموع أسفل الجدول.
- **الحالة:** مسودة أو مُرحَّل، وزر «حفظ كمسودة».
- **عمليات القائمة:** إضافة، **سجل التعديلات**، استيراد من جدول بيانات. المرشحات: حساب، وصف، تاريخ (مدى)، مصدر، رقم، حالة، مدى مبلغ، تاريخ الإنشاء.
- **إعدادات القيود:** ترقيم مستقل للقيود اليدوية عن الآلية، إظهار/إخفاء أعمدة الضريبة ومركز التكلفة والوسوم، حقل سعر الصرف (يدوي أو تلقائي)، **حقول مخصصة للقيود**، إلزام توزيع مراكز التكلفة في القيود اليدوية، السماح بتجاوز 100% في التوزيع.

### 2.3 توجيه الحسابات (Accounts Routing) — قلب الترحيل الآلي
صفحة بست تبويبات: **المبيعات، المشتريات، المخزون، الخزينة، الأذون المخزنية، السنة المالية**. لكل مفهوم محاسبي «نوع توجيه» (تعيين تلقائي / حساب محدد / إلغاء / بلا توجيه) وحسابه الرئيسي:

- **المبيعات:** العملاء (ذمم)، المبيعات، المرتجعات، الخصم المسموح به، حساب مبيعات المنتج (على مستوى المنتج)، التسوية، تكلفة المبيعات.
- **المشتريات:** الموردون (ذمم دائنة)، المشتريات (رأيتها تحت رمز 1210 أي مخزون/أصول)، مرتجعات المشتريات، الخصم المكتسب، التسوية.
- خيار **تعيين الحساب على مستوى البند** لكل نوع معاملة (فواتير بيع، فواتير شراء، أذون مخزنية) يضيف عمودًا لاختيار حساب القيد لكل سطر يدويًا.

### 2.4 الفترات المالية والإقفال
- **الفترات المالية:** اسم الفترة (مثل «1 سنة»)، تاريخ البداية والنهاية، وصف.
- **الفترات المغلقة:** نطاق تاريخ ومفتاح «نشط»؛ يمنع أي تعديل أو معاملة جديدة داخل النطاق.

### 2.5 مراكز التكلفة
شجرة (رئيسي وفرعي) تُسند إلى سطور القيود والمصروفات وبنود الفواتير، بتوزيع **نسبة مئوية أو مبلغ** على عدة مراكز.

### 2.6 الأصول الثابتة
حقول نموذج الأصل: الكود، الحساب الرئيسي، حساب النقدية، تاريخ الشراء، تاريخ بدء الخدمة، قيمة الشراء، قيمة الخردة، **طريقة الإهلاك**، العمر الإنتاجي، فترة الإهلاك، النسبة، القيمة الثابتة، تاريخ الإهلاك القادم، تاريخ انتهاء الإهلاك، الكمية/وحدات الأصل/سعر الوحدة، الموقع، الموظف، ضريبتان، العملة. عمليات الأصل تُنتج قيودًا (إنشاء، إهلاك، شطب، إعادة تقدير، بيع).

### 2.7 الخزائن والبنوك
كيان واحد (نوع: خزينة أو حساب بنكي) بالاسم والوصف والعملة والحالة والرصيد، **وخزينة افتراضية لكل موظف** تُسجَّل بها عملياته.

### 2.8 المصروفات والإيرادات (سندات الصرف والقبض)
- حقول المصروف: المبلغ، التصنيف، الرقم، التاريخ، **متكرر** (مع التكرار وتاريخ الانتهاء)، الوصف، مرفقات، المورد، **حساب فرعي واحد أو حسابات متعددة**، مراكز التكلفة، ضريبة، البائع، حفظ كمسودة. للإيراد الحقول نفسها بدون المورد.
- إعدادات: تصنيفات المصروفات، تصنيفات حسابات الدخل، **إلزام اختيار حساب المصروف/الدخل** (يضمن ظهورها بدقة في الأرباح والخسائر)، الخزينة الافتراضية للموظف.

### 2.9 الضرائب والترقيم
- **الضرائب:** اسم، نسبة، «متضمنة/غير متضمنة»؛ ضريبتان لكل بند (ضريبة 1 وضريبة 2).
- **الترقيم المتسلسل:** لكل نوع مستند (فاتورة، عميل، عرض سعر، مرتجع، إشعار دائن، فاتورة شراء، مرتجع شراء، مورد، **قيد تلقائي، قيد يدوي**، مصروف، سند قبض، أذون مخزن، أصل، مدفوعات…): الرقم التالي، التنسيق (أرقام/حروف)، عدد الخانات، عدم التكرار، البادئة (ثابتة أو متغيرة بالتاريخ) مع قواعد: المتابعة بعد آخر رقم، فصل التسلسل لكل بادئة، إعادة التصفير عند تغيير البادئة.

## 3. التقارير (ما يخص المحاسبة)

| المجموعة | التقارير |
|---|---|
| **الضرائب** | تقرير الضرائب (تفصيلي/ملخص)، **إقرار ضريبي** |
| **القوائم المالية** | قائمة الدخل، الميزانية العمومية، الربح والخسارة (**أساس الاستحقاق** أو **النقدي**) |
| **السيولة** | الحركات المالية، **التدفقات النقدية** |
| **دفتر الأستاذ** | **ميزان مراجعة** (مجاميع وأرصدة / أرصدة فقط)، **حساب مراجعة**، **حساب الأستاذ**، تقرير مراكز التكلفة، تقرير القيود (تفصيلي/ملخص)، دليل الحسابات، تقرير الأصول |
| **المصروفات** | حسب التصنيف، البائع، مدخل العملية، العميل؛ وحسب المدة (يومي/أسبوعي/شهري/سنوي) — كلها تفصيلي وملخص |
| **سندات القبض** | مقسّمة ومدة زمنية، بنفس الأسلوب |
| **أخرى** | الشيكات، الذمم المدينة والدائنة والمدفوعات المقدمة، ربحية حركات المخزون |

نمط ثابت: كل تقرير له نسختان **التفاصيل / الملخص**، ويُجمَّع حسب **يومي/أسبوعي/شهري/سنوي** أو حسب كيان (عميل، موظف، مندوب مبيعات، طريقة دفع، منتج، تصنيف، علامة).

## 4. ما لم أتأكد منه (لا يُبنى عليه)

- **محتوى** تقارير ميزان المراجعة وقائمة الدخل والميزانية: روابطها المباشرة التي خمّنتها أعادتني للرئيسية، ولم أفتحها من الفهرس. معروف الأسماء والتقسيم فقط.
- تبويبات التوجيه الأربعة الأخيرة (المخزون، الخزينة، الأذون، السنة المالية) رأيت أسماءها فقط.
- القيد الذي تولّده فاتورة مبيعات فعليًا (أي حساب يُدين وأيّه يُدائن): الحساب فارغ ولم أُنشئ بيانات. التصميم في [03](03-architecture.md) يعتمد على **المحاسبة القياسية**، لا على ما ينتجه المرجع.
- سلوك الإقفال السنوي وتدويل الأرباح إلى حساب 32.
- الأجزاء المرتبطة بالموارد البشرية (مسير الرواتب) والتصنيع والشيكات: خارج نطاق هذا العمل.
