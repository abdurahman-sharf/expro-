## 2. ما يثبت أن هذه هي النسخ الحالية

- صفحة [مواصفات الفاتورة الإلكترونية](https://zatca.gov.sa/en/E-Invoicing/SystemsDevelopers/Pages/E-Invoice-specifications.aspx) لا تسرد في 2026-11-20 إلا XML Implementation Standard وData Dictionary بتاريخ **2023-05-19** (نسختا `vF` و`vTrack`). لا إصدار أحدث منشور.
- صفحة [الأنظمة واللوائح](https://zatca.gov.sa/en/E-Invoicing/Introduction/LawsAndRegulations/Pages/default.aspx) تسرد اللائحة وقرار 2023-05-19 فقط.
- صفحة [الأدلة](https://zatca.gov.sa/en/E-Invoicing/Introduction/Guidelines/Pages/default.aspx) تسرد: دليل بوابة المطورين، والدليل التفصيلي، والدليل الفني التفصيلي، ودليل بوابة فاتورة، والدليل المبسط.
- صفحة [تنزيل SDK](https://zatca.gov.sa/en/E-Invoicing/SystemsDevelopers/ComplianceEnablementToolbox/Pages/DownloadSDK.aspx) تشترط قبول الشروط قبل التنزيل، وتنص على أن اجتياز التحقق بالـ SDK **لا يعني اعتماد الهيئة** للفواتير ولا يعفي من المتطلبات.
