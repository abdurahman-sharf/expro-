# سجل السجلات التجريبية

الوضع: **قراءة فقط — لم يُنشأ أي سجل.** المستخدم أكد التفويض وأن الشركة المفتوحة شركة ديمو، لكنه **لم يأذن صراحة بإنشاء
سجلات تجريبية**، فلم يُفعَّل وضع التجربة. لم تُرسل أي نماذج ولم يُضغط أي زر حفظ أو إجراء.

## ترتيب الحذف المقترح

لا يوجد ما يُحذف. إن فُعّل وضع التجربة لاحقاً (لاختبار الخلايا المحجوبة في `04a-scenario-matrix.json`)، فترتيب الحذف
بالعكس: الدفعات/السندات ← المرتجعات/الإشعارات ← الفواتير ← حركات المخزون والتحويلات والقيود اليدوية وإعادة التقييم ←
الأطراف (عملاء/موردون) ← الأصناف — والحذف بيد المستخدم أو بإذن صريح لكل عملية، مع ملاحظة أن بعض الأنظمة تمنع حذف ما له
قيود فيلزم إلغاؤه أو إصدار إشعار دائن أولاً.
