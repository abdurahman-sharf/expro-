# خريطة النظام المرجعي

## ملخص
الوحدات: 15 في الخريطة (14 تطبيقاً في المدير: مفعّلة 7، معطّلة 7؛ + وحدة "الإعدادات والنظام") · الشاشات: 52 ·
حسب النوع: form 15، list 12، settings 10، report 8، detail 4، dashboard 2، wizard 1 (انظر `01-sitemap.json`) ·
حسب العرض: server 51، spa 1 (قائمة العملاء تُملأ من الـ API).
بيئة التصفح: سطح مكتب 1440×900، نسبة البكسل 1. الصفحات قُرئت بـ `fetch` GET (قائمة محددة بعد `urlcheck`) مع تحقق بصري
بلقطات لعيّنة (لوحة المعلومات، نموذج العميل، نموذج الفاتورة، قائمة العملاء).

## التخطيط العام (وصف وظيفي)
ترويسة علوية: الشركة الحالية + مبدّل الشركات + محدد الفرع الحالي + قائمة المستخدم (الإعدادات). قائمة جانبية (يمين في RTL)
مجمّعة حسب الوحدة، وعنصر "المزيد…" مطوي. المحتوى: عنوان + زر "+ جديد" + جدول. النماذج صفحة كاملة بأزرار في الأسفل
(حفظ / حفظ كمسودة / إلغاء)، وأقسام "متقدم" مطوية، ونموذج فرعي مضمّن لإنشاء عميل من داخل الفاتورة.

## ترتيب الدراسة المقترح (المتّبع)
1. البيانات الأساسية: دليل الحسابات ← توجيه الحسابات ← الضرائب ← العملات ← الفروع والمستودعات ← العملاء والموردون والأصناف
2. المستندات: القيد اليدوي ← فاتورة المبيعات ← سند القبض ← فاتورة المشتريات ← التحويل المخزني ← إعادة التقييم
3. التقارير ← 4. الإعدادات والصلاحيات وZATCA
