# الأسئلة المفتوحة

> مرتّبة حسب الأهمية. **حرجة:** تمنع MVP أو تمس صحة القيود/الضريبة · **عالية:** تمس وحدة كاملة · **متوسطة:** سلوك ثانوي · **منخفضة:** تفضيل واجهة.
> "كيف يُحسم" يتطلب غالباً تنفيذ عملية: **في شركة الديمو فقط، وبإذن صريح لكل عملية** (الدراسة جرت في وضع القراءة فقط).
> الافتراض الآمن هو ما يبني عليه المنفّذ حتى الحسم (منقول إلى `08-build-brief.md` §7).
