## القوائم والفلاتر

- **الأعمدة:** العملة (رمز ISO + الاسم) · أساسية (✓) · آخر سعر (6 خانات عشرية) · تاريخ السعر · المصدر (يدوي).
- العملات المرصودة: الريال السعودي (أساسية، سعر 1.000000)، الدولار الأمريكي، اليورو — المصدر "يدوي" لكليهما.
- **نص ثابت مرئي:** حساب أرباح/خسائر فروق العملة **المحققة** = دور `fx` (5301)؛ **غير المحققة** = حساب "فروق تقييم العملات"
  (5302) **ويُعكس أول الفترة التالية**.
- لا فلاتر ولا تصدير.
