## القوائم والفلاتر

- **الحالة العامة:** المرحلة الثانية (الربط والتكامل) · البيئة: محاكاة (Simulation).
- **جدول الوحدات:** الوحدة (EGS، رمز يتضمن الفرع) · الفرع · أنواع الفواتير (ضريبية + مبسطة / مبسطة) · حالة الشهادة (CSID إنتاج فعّال / غير مربوط) · تاريخ الانتهاء.
