# سند قبض

- **المسار في القائمة:** المبيعات > سند قبض (أو: عرض فاتورة > تسجيل دفعة ?invoice={id})
- **نمط الرابط:** `/receipts/new`
- **النوع:** form
- **العرض / الاستخراج:** server · fetch · تحقق بصري: لا
- **الغرض الوظيفي:** تسجيل سند قبض على فاتورة مبيعات بمبلغ وتاريخ وحساب نقدية/بنك.
