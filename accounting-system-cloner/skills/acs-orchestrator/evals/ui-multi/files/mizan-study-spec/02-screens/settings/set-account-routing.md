## القوائم والفلاتر

| التبويب | العملية | نوع التوجيه | الحساب (الدور) |
|---|---|---|---|
| المبيعات | إيراد المبيعات | تلقائي | 4101 (`sales`) |
| المبيعات | ضريبة المبيعات | تلقائي | 2201 (`income_tax`) |
| المبيعات | ذمم العملاء | تلقائي (حساب فرعي لكل عميل) | 1201 (`clients`) |
| المشتريات | البنود النصية الحرة في فواتير الشراء | تلقائي | 5102 (`purchases`) |
| المشتريات | ضريبة المشتريات | تلقائي (يُنشأ عند أول استخدام) | — |
| المشتريات | ذمم الموردين | تلقائي (حساب فرعي لكل مورد) | 2101 (`suppliers`) |
| المخزون | المخزون | تلقائي | 1301 (`stores`) |
| المخزون | تكلفة المبيعات | تلقائي | 5101 (`sales_cost`) |
| المخزون | الرصيد الافتتاحي للأصناف | تلقائي | 3301 (`opening_balance`) |
| المخزون | فروقات الجرد | بلا توجيه | — |

- أنواع التوجيه المرصودة: "تلقائي"، "تلقائي (حساب فرعي لكل طرف)"، "تلقائي (يُنشأ عند أول استخدام)"، "بلا توجيه". لم يُرصد "مُلغى".
- لا تبويب للعملات (حسابا الفروق في `gl-currencies`) ولا للنقدية ولا للفروع.
- العرض للقراءة فقط (لا نموذج تعديل ظاهر).
