# إعادة تقييم العملات

- **المسار في القائمة:** المحاسبة > إعادة تقييم العملات
- **نمط الرابط:** `/fx/revaluation`
- **النوع:** wizard
- **العرض / الاستخراج:** server · fetch · تحقق بصري: لا
- **الغرض الوظيفي:** إعادة تقييم أرصدة الحسابات والعملاء والموردين بالعملات الأجنبية بسعر نهاية الفترة وإنشاء قيد فروق غير محققة يُعكس تلقائياً أول يوم في الفترة التالية (نص مرئي).

## الجداول الفرعية (سطور المستند)

**جدول المعاينة (قبل التنفيذ):**

| العمود | المعنى |
|---|---|
| الحساب | الحساب/الطرف ذو الرصيد الأجنبي (مثال مرصود: حساب عميل فرعي بعملة الدولار) |
| الرصيد بالعملة | الرصيد بعملة الطرف |
| السعر الدفتري | متوسط السعر المسجّل به الرصيد (4 خانات) |
| سعر التقييم | سعر تاريخ التقييم |
| الفرق | `الرصيد بالعملة × (سعر التقييم − السعر الدفتري)` بالعملة الأساسية |
