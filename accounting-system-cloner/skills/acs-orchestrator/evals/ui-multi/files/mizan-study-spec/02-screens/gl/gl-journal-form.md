# قيد يومية يدوي

- **المسار في القائمة:** المحاسبة > القيود اليومية > + قيد يدوي
- **نمط الرابط:** `/journal/new`
- **النوع:** form
- **العرض / الاستخراج:** server · fetch · تحقق بصري: لا
- **الغرض الوظيفي:** قيد يومية يدوي متعدد الأسطر مع مركز تكلفة وبيان لكل سطر، بحفظ كمسودة أو ترحيل، وخيار التكرار الشهري.

## الجداول الفرعية (سطور المستند)

| العمود | النوع | إلزامي | القيمة الافتراضية | التحقق / القيود | مصدر القائمة | ملاحظات |
|---|---|---|---|---|---|---|
| الحساب | قائمة مرجعية | نعم [مُستنتج] | أول حساب | حسابات الحركة فقط [مُستنتج] | الحسابات | لا عمود عملة ولا سعر صرف |
| مدين | مبلغ | شرطي | — | `min=0`، `step=0.01` | — | مدين أو دائن [مُستنتج] |
| دائن | مبلغ | شرطي | — | `min=0`، `step=0.01` | — | |
| مركز التكلفة | قائمة مرجعية | شرطي (إن كان الحساب يتطلبه) | فارغ | — | مراكز التكلفة (الإدارة، المبيعات) | |
| بيان السطر | نص | لا | — | — | — | |

**الحسابات:** `الفرق = Σ مدين − Σ دائن`؛ الترحيل ممنوع إن لم يكن صفراً (الحفظ كمسودة مسموح [مُستنتج]).
**التقريب:** خانتان (`step=0.01`).
