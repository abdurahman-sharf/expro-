## الأثر المحاسبي

مثال البنية المرصودة لفاتورة بيع مخزنية معتمدة (بلا مبالغ حقيقية):

| القيد | الحساب | مدين | دائن |
|---|---|---|---|
| 1 (فاتورة) | حساب العميل الفرعي تحت `clients` | الإجمالي شامل الضريبة | |
| 1 | `sales` | | الصافي |
| 1 | `income_tax` (ضريبة المخرجات) | | الضريبة |
| 2 (تكلفة) | `sales_cost` | تكلفة البضاعة | |
| 2 | `stores` | | تكلفة البضاعة |

متسق: Σ المدين = Σ الدائن لكل قيد، والضريبة = 15% من الصافي.
