# الأدوار والصلاحيات وسير العمل

المصادر: `set-roles`، `set-approvals`، `sys-audit-log` (قراءة فقط؛ نموذج "دور جديد" يعيد 404 فلم تُقرأ مجموعات الصلاحيات كاملة).
أسماء المستخدمين وبريدهم في الشاشة **لم تُنسخ**.

## الأدوار
| الدور | المصدر | ملاحظات |
|---|---|---|
| مدير النظام | مرئي | مصفوفته غير معروضة؛ [مُستنتج] كل الصلاحيات |
| محاسب | مرئي | المصفوفة الوحيدة المعروضة (أدناه) |
| مندوب مبيعات | مرئي | مصفوفته غير معروضة (Q-56)؛ مرتبط بحقل "مندوب المبيعات" في الفاتورة [مُستنتج] |
| مدير فرع | مرئي | يظهر في سلسلة اعتماد الفواتير > الحد |
| مدير مالي | **غير موجود في قائمة الأدوار**، يظهر في حدود الاعتماد | AN-09 |

## مصفوفة دور "محاسب" (مرئية)
| الشاشة/الكيان | عرض | إضافة | تعديل | حذف | اعتماد | ترحيل | طباعة | تصدير |
|---|---|---|---|---|---|---|---|---|
| فواتير المبيعات | ✓ | ✓ | ✓ (مسودة فقط) | ✗ | ✗ | — (غير معروض) | ✓ | — |
| القيود اليومية | ✓ | ✓ | ✓ | ✗ | ✗ | — (غير معروض؛ زر "ترحيل" في النموذج) | ✓ | — |
| دليل الحسابات | ✓ | ✗ | ✗ | ✗ | — | — | ✓ | — |
| الإعدادات | ✗ | ✗ | ✗ | ✗ | — | — | ✗ | — |
| بقية الشاشات (العملاء، الموردون، المشتريات، المخزون، التقارير) | غير معروضة في المصفوفة — Q-56 | | | | | | | |

**الصلاحيات الخاصة (مرئية لدور المحاسب):** رؤية التكلفة ✗ · تعديل سعر البيع ✓ · تجاوز حد الائتمان ✗.
لا صلاحية "البيع بالسالب" ولا "تغيير التاريخ" ولا "الترحيل في فترة مقفلة" — غير موجودة في النظام المرجعي (مضافة كمقترح).

## نطاق الصلاحيات
- **الكل / الخاص به:** لا يظهر نطاق "الخاص به" في المصفوفة ⇒ غير موجود في النظام المرجعي ظاهرياً. المقترح: حقل `created_by` على المستندات و`scope` في `role_permission` (اختياري للمندوب) — [مُستنتج].
- **الفروع:** "المستخدم مقيّد بفروعه المسموحة (صلاحية الفرع على مستوى المستخدم)" (مرئي) ⇒ جدول `user_branch` وفلترة كل القوائم والتقارير والمستندات بالفروع المسموحة، ومحدد الفرع في الترويسة يعرض المسموحة فقط [مُستنتج].

## الفصل بين الصلاحيات الدقيقة
| الإجراء | مستقل؟ | المصدر |
|---|---|---|
| حفظ مسودة / إصدار (اعتماد) | **مستقلان** — "إضافة ✓" و"اعتماد ✗" للمحاسب | مرئي |
| تعديل قبل الإصدار / بعده | "تعديل (مسودة فقط)" ⇒ التعديل بعد الإصدار غير مسموح للمحاسب | مرئي |
| حذف | مستقل (✗) | مرئي |
| تغيير السعر | صلاحية خاصة مستقلة | مرئي |
| تغيير التاريخ | غير موجود | — |
| الترحيل (للقيود) | غير معروض في المصفوفة رغم زر "ترحيل" | Q-61 |

## صلاحيات الفترات المقفلة
- الإقفال صلب: "الفترة المقفلة تمنع ترحيل أي مستند بتاريخ داخلها" (مرئي). لا استثناء لدور ظاهر؛ من يملك إقفال/إعادة فتح الفترة غير معروض (Q-24) — المقترح: صلاحية `settings.periods.manage` لمدير النظام فقط.

## حدود الاعتماد وسلاسله (قيم إعداد)
| المستند | الحد | المعتمد | المراحل |
|---|---|---|---|
| فاتورة مبيعات | ≤ 50,000.00 | محاسب | 1 |
| فاتورة مبيعات | > 50,000.00 | مدير فرع ← مدير مالي | 2 |
| سند صرف | > 10,000.00 | مدير مالي | 1 (لا شاشة سند صرف — Q-22) |
- **قاعدة مقترحة (تحسم AN-09):** الاعتماد = صلاحية `approve` **و** قاعدة حد مطابقة؛ أثناء انتظار الاعتماد الحالة `pending_approval` (لا رقم ولا قيد) [مُستنتج]؛ الرفض يعيد للمسودة [مُستنتج]. أين يظهر زر الاعتماد: غير متحقق (Q-23).

## ربط مجموعات الصلاحيات بالوحدات
- غير مقروء (نموذج الدور 404). المقترح: كل `permission` يحمل `module_code`، والوحدة المعطّلة تخفي مجموعاتها وتُسقط صلاحياتها فعلياً [مُستنتج].

## سجل التدقيق
- يُسجَّل: الوقت، المستخدم، الإجراء (مثل "اعتماد")، السجل (رقم المستند) — مرئي. لا قيم قبل/بعد ولا فلاتر (غير موجود في النظام المرجعي؛ المقترح إضافتهما — Q-57).
- يُعرض في "المزيد… > سجل التدقيق".
