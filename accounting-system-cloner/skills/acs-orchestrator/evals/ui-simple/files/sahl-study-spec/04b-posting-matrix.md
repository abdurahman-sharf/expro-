# مصفوفة الترحيل

> **إلى الوكيل المنفّذ:** كل سطر قاعدة ترحيل. ابنِ محرك ترحيل يقرأ هذه القواعد كبيانات قابلة للإعداد (لا قيود مكتوبة في الكود)، مع جدول
> توجيه يربط كل **دور** بحساب في دليل حسابات الشركة. لكل سطر اختبار آلي (T-PM في `08-build-brief.md`).
> **المصدر:** **قيد قائم** = بنية مقروءة من قيد مرحّل موجود في النظام المرجعي (قراءة لا إنشاء) · **إعداد** = من شاشة توجيه الحسابات ·
> **[مُستنتج]** = من المبادئ المحاسبية. **لا يوجد مصدر "تجربة"**: الدراسة في وضع القراءة فقط، وكل خلايا `04a-scenario-matrix.json` محجوبة.
> الأرقام وهمية؛ لا أرقام حسابات حقيقية — أدوار ومعادلات فقط.

## معجم الأدوار
| الدور | المعنى | حساب فرعي تلقائي؟ | المصدر |
|---|---|---|---|
| `clients` | ذمم العملاء (حساب رقابة تجميعي) | **نعم، لكل عميل** (`<رمز>-NNN`) | إعداد + الدليل + قيد قائم (القيد على الحساب الفرعي) |
| `suppliers` | ذمم الموردين (تجميعي) | **نعم، لكل مورد** | إعداد + الدليل |
| `sales` | إيراد المبيعات | — (يمكن تجاوزه بحساب إيراد الصنف) | إعداد + قيد قائم |
| `sales_cost` | تكلفة المبيعات | — (يمكن تجاوزه بحساب تكلفة الصنف) | إعداد + قيد قائم |
| `purchases` | المشتريات غير المخزنية والبنود الحرة | — | إعداد |
| `stores` | المخزون | لا (لا مستودعات) | إعداد + قيد قائم |
| `vat_output` | ضريبة المخرجات (اسمه في المرجع `income_tax`) | لا | إعداد + قيد قائم |
| `vat_input` | ضريبة المدخلات | المرجع: "يُنشأ عند أول استخدام" — **في النظام الجديد: يُزرع مسبقاً** (AN-08) | إعداد |
| `treasury` / `bank` | الصندوق / البنك | لا | الدليل + نموذج السند |
| `opening_balance` | أرصدة افتتاحية (حقوق ملكية مؤقت، يُقفل) | — | إعداد |
| `retained_earnings` | الأرباح المحتجزة | — | الدليل |
| `other_payables` | أطراف دائنة أخرى | — | الدليل (لا يُستخدم في أي قاعدة أدناه) |
| `fx_gain_loss` | فروق العملة (اسمه في المرجع `fx`) | — | الدليل (بلا توجيه) |
| `sales_discount` | خصم مسموح به | — | مقترح اختياري (Q-40) — غير موجود في المرجع |

## معجم المعادلات
`gross_line = qty × price` · غير شامل: `net_line = gross_line`، `tax_line = net_line × rate` · شامل: `tax_line = gross_line × rate ÷ (1 + rate)`،
`net_line = gross_line − tax_line` · `net = Σ net_line − doc_discount_alloc` · `tax = Σ tax_line` (بعد توزيع الخصم) · `total = net + tax` ·
`cost = Σ(qty × unit_cost)` (متوسط متحرك [مُستنتج]) · `paid` = مبلغ السند · `fx_diff = amount_fc × (rate_payment − rate_invoice)`
