# الأسئلة المفتوحة

> الدراسة نُفّذت في **وضع القراءة فقط** دون انتظار المستخدم (بطلبه). كل ما يحتاج قراراً أو تنفيذ عملية سُجّل هنا ولم يُنفَّذ.
> "كيف يُحسم" يصف العملية المطلوبة؛ لا يُنفَّذ أي منها إلا في شركة الديمو **وبإذن صريح لكل عملية** (أو بتفعيل وضع التجربة — Q-02).
> الأهمية: **حرجة** تمنع MVP أو تمس صحة القيود/الضريبة · **عالية** تمس وحدة كاملة · **متوسطة** سلوك ثانوي · **منخفضة** تفضيل واجهة.
