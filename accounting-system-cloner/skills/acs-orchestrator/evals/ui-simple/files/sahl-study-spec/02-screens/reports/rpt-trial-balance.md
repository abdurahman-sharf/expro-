# ميزان المراجعة

- **المسار في القائمة:** التقارير > ميزان المراجعة
- **نمط الرابط:** `/reports/trial-balance`
- **النوع:** report
- **العرض / الاستخراج:** server · browse · تحقق بصري: لا
- **الغرض الوظيفي:** أرصدة الحسابات (افتتاحي + حركة + ختامي) لفترة، بمستوى تفصيل قابل للاختيار.

## الجداول الفرعية (سطور المستند)
| العمود | المعادلة (بدلالة الجداول) |
|---|---|
| الحساب | الرمز + الاسم |
| افتتاحي مدين/دائن | صافي `Σ(debit − credit)` قبل "من" (موجب ⇒ مدين، سالب ⇒ دائن) |
| حركة مدين | `Σ debit` بين من وإلى |
| حركة دائن | `Σ credit` بين من وإلى |
| ختامي مدين/دائن | افتتاحي + حركة، يُعرض في جهة واحدة حسب الإشارة |
(التفاصيل في `06-reports.md#rpt-01`.)
