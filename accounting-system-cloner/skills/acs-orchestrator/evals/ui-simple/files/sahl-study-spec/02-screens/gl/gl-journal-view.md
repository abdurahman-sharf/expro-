# عرض قيد

- **المسار في القائمة:** المحاسبة > القيود اليومية > رقم القيد
- **نمط الرابط:** `/journal/view/{id}`؛ المحتوى داخل iframe من نفس النطاق: `/journal/view/{id}/frame`
- **النوع:** detail
- **العرض / الاستخراج:** server (الإطار المضمّن قُرئ عبر `contentDocument`) · browse · تحقق بصري: نعم (ضمن صفحة الفاتورة)
- **الغرض الوظيفي:** عرض رأس القيد ومصدره وأسطره.

## الحقول
| الحقل | النوع | ملاحظات |
|---|---|---|
| رقم القيد | نص | `JE-YYYY-NNNNN` |
| المصدر | نص | "فاتورة مبيعات INV-…" / "تكلفة INV-…" |
| أسطر: الحساب، مدين، دائن | جدول | الحساب يُعرض "الرمز + الاسم" |

لا يُعرض: التاريخ، البيان، مركز التكلفة، الحالة، المستخدم — داخل الإطار.
