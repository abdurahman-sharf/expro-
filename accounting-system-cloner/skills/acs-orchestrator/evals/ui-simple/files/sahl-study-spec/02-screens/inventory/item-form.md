## الأثر المحاسبي
الرصيد الافتتاحي (إن أُدخل) — حسب التوجيه المعلن في `set-account-routing` (تبويب المخزون):

| الحساب | مدين | دائن | مصدر الحساب الافتراضي |
|---|---|---|---|
| المخزون (`stores`) | الكمية × تكلفة الوحدة | | التوجيه: المخزون 1301 |
| أرصدة افتتاحية (`opening_balance`) | | الكمية × تكلفة الوحدة | التوجيه: "الرصيد الافتتاحي للأصناف" ← 3301 |

**غير متحقق** (يتطلب حفظ صنف برصيد افتتاحي — وضع التجربة): هل يرحّل النظام فعلاً إلى 3301 أم إلى حساب آخر (مثل
"أطراف دائنة أخرى" 2301 الموجود بدور `other_payables`)؟ — Q-32، خلية SM-008 محجوبة.
