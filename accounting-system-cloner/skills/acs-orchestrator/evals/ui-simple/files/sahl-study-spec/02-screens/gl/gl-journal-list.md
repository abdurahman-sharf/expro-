# القيود اليومية

- **المسار في القائمة:** المحاسبة > القيود اليومية
- **نمط الرابط:** `/journal`
- **النوع:** list
- **العرض / الاستخراج:** server · browse · تحقق بصري: لا
- **الغرض الوظيفي:** دفتر اليومية: كل القيود الآلية (من المستندات) واليدوية، مع الانتقال لعرض القيد أو إنشاء قيد يدوي.

لا ينطبق.

## النماذج المضمّنة

## الأزرار والإجراءات
| الإجراء | متى يظهر | الأثر المتوقع | قابل للعكس؟ |
|---|---|---|---|
| + قيد يدوي | دائماً | يفتح `gl-journal-form` | — |

## الحالات ودورة الحياة
انظر `gl-journal-form`. القائمة لا تعرض عمود الحالة (مسودة/مرحّل) — انظر Q-14.

## القوائم والفلاتر
- **الأعمدة:** الرقم (`JE-YYYY-NNNNN`) · التاريخ · المصدر (نص: "فاتورة مبيعات INV-…" أو "تكلفة INV-…") · المبلغ (مجموع المدين)
- **الفرز الافتراضي:** تصاعدي بالرقم
- **الفلاتر / البحث / التصدير:** لا يوجد
- **التصفح:** صفحة واحدة

## الأثر المحاسبي
لا ينطبق. ملاحظة مرئية: فاتورة البيع المعتمدة تولّد **قيدين متتاليين** (إيراد ثم تكلفة) يحمل كل منهما المصدر نفسه.

## الآثار الجانبية
لم تُختبر: وضع القراءة.

## العلاقات

- شاشات مرتبطة: `gl-journal-view`، `gl-journal-form`، `sales-invoice-view`.
