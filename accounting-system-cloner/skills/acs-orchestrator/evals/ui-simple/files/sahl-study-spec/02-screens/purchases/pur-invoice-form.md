# فاتورة مشتريات جديدة

- **المسار في القائمة:** المشتريات > فواتير المشتريات > + فاتورة مشتريات
- **نمط الرابط:** `/purchases/invoices/new` (الإرسال POST `/purchases/invoices` — لم يُرسل)
- **النوع:** form
- **العرض / الاستخراج:** server · browse · تحقق بصري: لا
- **الغرض الوظيفي:** تسجيل فاتورة مورد ببنود مخزنية أو خدمية أو نصية حرة وضريبتها، وإصدارها مباشرة.

## الجداول الفرعية (سطور المستند)
3 أسطر ثابتة كما في فاتورة البيع:

| العمود | النوع | إلزامي | القيمة الافتراضية | التحقق / القيود | مصدر القائمة | ملاحظات |
|---|---|---|---|---|---|---|
| الصنف | قائمة مرجعية | لا | "— بند نصي حر —" | — | الأصناف (مخزني وخدمي) | البند الحر بلا صنف |
| الوصف | نص | شرطي | — | التلميح: "إلزامي للبند الحر" | — | |
| الكمية | عشري(3) | لا | — | `min=0`، `step=0.001` | — | |
| التكلفة | مبلغ | لا | — | `min=0`، `step=0.01` | — | (بدل "السعر") |
| الضريبة | قائمة ثابتة | لا | 15% | 15% / 0% | — | |

**الحسابات:** `صافي السطر = الكمية × التكلفة`؛ `ضريبة السطر = صافي السطر × النسبة` (غير شامل دائماً — لا خيار شامل) [مُستنتج].

## الأثر المحاسبي
متوقع من التوجيه المعلن (`set-account-routing`، تبويب المشتريات/المخزون) — **غير مرصود فعلياً**:

| نوع البند | الحساب | مدين | دائن | مصدر الحساب الافتراضي |
|---|---|---|---|---|
| مخزني | المخزون (`stores`) | net | | التوجيه: المخزون 1301 [مُستنتج] |
| خدمي | المشتريات (`purchases`) أو حساب مصروف الصنف | net | | [مُستنتج] — غير موثّق في التوجيه |
| نصي حر | المشتريات (`purchases`) 5102 | net | | التوجيه: "البنود النصية الحرة في فواتير الشراء" |
| الكل | ضريبة المدخلات (`vat_input`) | tax | | التوجيه: "يُنشأ عند أول استخدام" |
| الكل | حساب المورد الفرعي (`suppliers`) | | total | التوجيه: حساب فرعي لكل مورد |

خلايا المصفوفة المحجوبة: SM-005 (مخزني)، SM-006 (خدمي)، SM-007 (نصي حر) — أهمها التحقق أن البند النصي الحر يذهب فعلاً إلى
`purchases` لا إلى `sales_cost` (Q-37، حرجة).
