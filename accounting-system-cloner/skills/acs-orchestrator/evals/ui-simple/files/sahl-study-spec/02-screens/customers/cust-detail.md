# بطاقة العميل

- **المسار في القائمة:** المبيعات > العملاء > اسم العميل
- **نمط الرابط:** `/customers/{id}`؛ التبويبات `/customers/{id}?tab=invoices|receipts|statement`
- **النوع:** detail
- **العرض / الاستخراج:** server · browse · تحقق بصري: لا
- **الغرض الوظيفي:** بيانات العميل الأساسية + فواتيره وسنداته وكشف حسابه بالرصيد التراكمي.

بطاقات العملاء الأخرى (`{id}` غير الأول) أعادت 404 رغم ظهور روابطها في القائمة — خلل في المرجع.
