# حساب جديد

- **المسار في القائمة:** المحاسبة > دليل الحسابات > + حساب جديد
- **نمط الرابط:** `/accounts/new` (الإرسال POST `/accounts` — لم يُرسل)
- **النوع:** form
- **العرض / الاستخراج:** server · browse · تحقق بصري: لا
- **الغرض الوظيفي:** إضافة حساب تحت حساب أب، بتحديد نوعه وطبيعته وخصائصه السلوكية.
