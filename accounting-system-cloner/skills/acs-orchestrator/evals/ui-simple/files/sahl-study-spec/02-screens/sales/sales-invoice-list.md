## الأزرار والإجراءات
| الإجراء | متى يظهر | الأثر المتوقع | قابل للعكس؟ |
|---|---|---|---|
| + فاتورة جديدة | دائماً | يفتح `sales-invoice-form` | — |
| رقم الفاتورة (رابط) | لكل صف | يفتح `sales-invoice-view` | — |
| إجراءات ← عرض | لكل صف | يفتح `sales-invoice-view` | — |
| إجراءات ← إلغاء التسليم | **لكل صف بكل الحالات** | رابط GET `/sales/invoices/make_undelivered/{id}` يغيّر حالة التسليم فوراً (لم يُطلب) | بإعادة التسليم [مُستنتج] |
| إجراءات ← حذف | **لكل صف بكل الحالات، بما فيها المعتمدة** | رابط GET `/sales/invoices/delete/{id}` يحذف فوراً بلا تأكيد (لم يُطلب) | لا |
