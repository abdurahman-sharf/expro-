# عرض فاتورة مبيعات

- **المسار في القائمة:** المبيعات > فواتير المبيعات > رقم الفاتورة
- **نمط الرابط:** `/sales/invoices/{id}`؛ القيد في iframe `/journal/view/{je_id}/frame`
- **النوع:** detail
- **العرض / الاستخراج:** server (محتوى الإطار عبر `contentDocument`) · browse · تحقق بصري: نعم
- **الغرض الوظيفي:** ملخص الفاتورة وحالتها وحالة تسليمها والمدفوع، وقيودها المحاسبية، والانتقال لتسجيل دفعة.

## الحقول
| الحقل | النوع | ملاحظات |
|---|---|---|
| رقم الفاتورة (عنوان) | نص | "—" للمسودة |
| العميل | مرجع | |
| الحالة | قائمة ثابتة | مسودة / معتمدة / مدفوعة جزئياً (+ مدفوعة [مُستنتج]) |
| التسليم | قائمة ثابتة | مُسلَّم / غير مُسلَّم [مُستنتج] |
| الإجمالي | مبلغ | |
| المدفوع | مبلغ | `Σ السندات المخصصة للفاتورة` [مُستنتج] |
| القيود المحاسبية | إطار مضمّن | قيد الإيراد فقط (قيد التكلفة لا يظهر هنا، فقط في دفتر اليومية)؛ للمسودة: "لا قيود (مسودة)" |

لا تُعرض أسطر الفاتورة ولا ملخص الضريبة في صفحة العرض.

## الحقول الشرطية والمتقدمة
لا ينطبق.

## النماذج المضمّنة
لا ينطبق.

## الجداول الفرعية (سطور المستند)
أسطر القيد في الإطار: الحساب، مدين، دائن (انظر `gl-journal-view`).

## الأزرار والإجراءات
| الإجراء | متى يظهر | الأثر المتوقع | قابل للعكس؟ |
|---|---|---|---|
| تسجيل دفعة | **كل الحالات** (حتى المسودة) | يفتح `sales-receipt-form` بالمعامل `?invoice={id}`؛ المعامل لا يختار الفاتورة مسبقاً (مرصود) | — |
| معاينة الطباعة | كل الحالات | `/sales/invoices/{id}/print` — **404** (`sales-invoice-print`) | — |
| إجراءات ← إلغاء التسليم | كل الحالات | GET ينفّذ فوراً (لم يُطلب) | — |
| إجراءات ← حذف الفاتورة | كل الحالات | GET ينفّذ فوراً (لم يُطلب) | لا |

## الحالات ودورة الحياة
انظر `sales-invoice-form`. **تناقضات مرصودة في السجلات القائمة:** فاتورة بحالة "مدفوعة جزئياً" والمدفوع 0.00 و"لا قيود
(مسودة)" (AN-02)؛ فاتورة مسودة بحالة تسليم "مُسلَّم" (AN-05).
