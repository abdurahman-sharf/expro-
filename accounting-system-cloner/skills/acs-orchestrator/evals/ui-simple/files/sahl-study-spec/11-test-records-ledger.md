# سجل السجلات التجريبية

**الوضع: قراءة فقط — لم يُنشأ أي سجل.**

المستخدم أكّد التفويض وأن الشركة المدروسة شركة ديمو في بيئة اختبار محلية، لكنه لم يأذن صراحةً بإنشاء سجلات، فبقيت الدراسة في وضع
القراءة (Q-02). لم يُضغط أي زر حفظ أو إصدار أو ترحيل أو حذف، ولم يُطلب أي رابط إجراء؛ كل طلب غير GET كان محجوباً على مستوى المتصفح الآلي.

## ترتيب الحذف المقترح

لا شيء للحذف — لم تُنشئ الدراسة أي سجل. إن فُعّل وضع التجربة لاحقاً (Q-02) فالترتيب: الدفعات ← المرتجعات/الإشعارات ← الفواتير ←
حركات المخزون والقيود اليدوية ← الأطراف ← المنتجات، والحذف بيد المستخدم أو بإذن صريح لكل عملية.
