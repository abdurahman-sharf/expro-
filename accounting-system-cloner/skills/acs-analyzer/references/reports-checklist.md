# قائمة فحص التقارير

## لكل تقرير، وثّق في `06-reports.md`

```markdown
## RPT-<nn>: <اسم التقرير>
- **الشاشة:** `<screen-id>` · **الغرض:** …
- **المعايير والفلاتر:** | الفلتر | النوع | إلزامي | افتراضي | ملاحظات |
- **الأعمدة:** | العمود | المعادلة (بدلالة الجداول) | التنسيق |
- **التجميع والمستويات:** (حسب الحساب الأب؟ قابل للتوسيع؟ إخفاء الأرصدة الصفرية؟)
- **الإجماليات:** …
- **المقارنات:** فترة سابقة / سنة سابقة / موازنة / نسبة التغير
- **التصدير والطباعة:** Excel / PDF / CSV / جدولة إرسال
- **التفاعل:** النقر على رقم ← تقرير تفصيلي؟ (drill-down إلى كشف الحساب ثم المستند)
- **اختبار التحقق المقترح للمنفّذ:** …
```

اكتب المعادلات بدلالة نموذج البيانات، مثلاً:
`رصيد الحساب في نهاية الفترة = Σ(journal_line.debit − journal_line.credit) حيث entry.status='posted'
و entry.date ≤ نهاية الفترة، مضروباً في (+1 لطبيعة مدين، −1 لطبيعة دائن)`.

## التقارير الشائعة — ما تبحث عنه في كل منها

| التقرير | أسئلة خاصة |
|---|---|
| ميزان المراجعة | أرصدة فقط أم (افتتاحي + حركة + ختامي)؟ مستوى الحسابات؟ يشمل غير المرحّل؟ حسب فرع/مركز تكلفة؟ |
| قائمة الدخل | تصنيف المجموعات (إيرادات، تكلفة، مجمل ربح، مصروفات تشغيلية، صافي)؟ من أين يأتي التصنيف (نوع الحساب أم إعداد تقارير)؟ |
| المركز المالي | كيف يظهر صافي ربح الفترة غير المقفلة ضمن حقوق الملكية؟ |
| التدفقات النقدية | مباشرة أم غير مباشرة؟ كيف تُصنّف الحسابات (تشغيلي/استثماري/تمويلي)؟ |
| كشف حساب (عام/عميل/مورد) | رصيد افتتاحي، رصيد تراكمي لكل سطر، عملة الحساب مقابل الأساسية، ربط بالمستند |
| أعمار الديون | الشرائح (0–30، 31–60…) قابلة للتعديل؟ حسب تاريخ الفاتورة أم الاستحقاق؟ معاملة الدفعات غير المخصصة؟ |
| تقارير الضريبة | إقرار ضريبة القيمة المضافة بخاناته، تفصيل المخرجات/المدخلات، التعديلات (إشعارات) |
| تقارير المخزون | الأرصدة بالكمية والقيمة، حركة صنف، تقييم المخزون في تاريخ، أصناف تحت حد الطلب، فروقات الجرد |
| تقارير المبيعات/المشتريات | حسب عميل/صنف/مندوب/فرع، الربحية (السعر − التكلفة) |
| دفتر الأستاذ / دفتر اليومية | فلاتر الحساب والتاريخ والمستند |
| تقارير البنوك | حركة البنك، التسوية البنكية، الشيكات حسب الحالة |
| الأصول | جدول الإهلاك، سجل الأصول، القيمة الدفترية |

## تحقق الاتساق (إلزامي قبل إغلاق المرحلة)
- ميزان المراجعة: مجموع المدين = مجموع الدائن = مجموع أسطر القيود المرحّلة.
- صافي الربح في قائمة الدخل = الفرق المرحّل إلى حقوق الملكية في المركز المالي.
- رصيد العميل في كشف الحساب = إجمالي أعمار الديون للعميل نفسه = رصيد حساب الرقابة (إن وُجد دفتر مساعد).
- قيمة المخزون في تقرير التقييم = رصيد حساب المخزون (في الجرد المستمر).
أي تقرير لا تستطيع كتابة معادلته من نموذج البيانات يعني نقصاً في النموذج: أكمله أو سجّل سؤالاً.
