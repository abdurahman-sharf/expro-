# قوالب الطباعة

ملفات `ui/print/<name>.html` بقياس A4 (`.print-doc` في `proto.css`، و`@page`)، بهوية المستخدم وبيانات وهمية. تربط
`kit/tokens.css` و`kit/proto.css` (لا تحتاج `proto.js`). كل قالب يبدأ بجدول صغير "العناصر الإلزامية" في تعليق HTML أو
في `ui/print/README.md` يذكر من أين جاء كل عنصر.

| الملف | القالب |
|---|---|
| `tax-invoice.html` | فاتورة ضريبية (B2B) |
| `simplified-invoice.html` | فاتورة ضريبية مبسطة (B2C) — تصلح أيضاً لعرض إيصال حراري ضيق بنسخة `@media` |
| `credit-note.html` / `debit-note.html` | إشعار دائن / مدين |
| `receipt-voucher.html` / `payment-voucher.html` | سند قبض / سند صرف |
| `account-statement.html` | كشف حساب (رصيد افتتاحي، حركات، رصيد تراكمي، ختامي) |
| `report.html` | قالب تقرير عام (رأس الشركة، المعايير، الجدول، الإجماليات، الترقيم، تاريخ الطباعة) |

## العناصر الإلزامية في السعودية (من متطلبات الفوترة الإلكترونية العامة)

تحقق من أحدث المواصفات الرسمية قبل التنفيذ؛ القائمة توجيهية:

| العنصر | ضريبية | مبسطة | إشعار دائن/مدين |
|---|---|---|---|
| عنوان المستند: "فاتورة ضريبية" / "فاتورة ضريبية مبسطة" / "إشعار دائن" / "إشعار مدين" | ✓ | ✓ | ✓ |
| رقم تسلسلي فريد، وتاريخ ووقت الإصدار | ✓ | ✓ | ✓ |
| اسم البائع وعنوانه ورقمه الضريبي (15 رقماً) | ✓ | ✓ | ✓ |
| اسم المشتري وعنوانه الوطني ورقمه الضريبي (إن كان مسجلاً) | ✓ | — | ✓ |
| لكل سطر: الوصف، الكمية، سعر الوحدة، الخصم، نسبة الضريبة، مبلغ الضريبة، الإجمالي شامل الضريبة | ✓ | مختصر | ✓ |
| الإجمالي قبل الضريبة، إجمالي الضريبة (مجمّعاً حسب النسبة)، الإجمالي المستحق — بالريال | ✓ | ✓ | ✓ |
| رمز QR (الحقول: اسم البائع، الرقم الضريبي، الطابع الزمني، الإجمالي مع الضريبة، الضريبة) | ✓ | ✓ إلزامي | ✓ |
| رقم الفاتورة الأصلية وسبب الإصدار | — | — | ✓ |
| سبب الإعفاء أو النسبة الصفرية للسطر المعني | عند الحاجة | عند الحاجة | عند الحاجة |
| اللغة العربية (ثنائية اللغة مسموحة) | ✓ | ✓ | ✓ |

في النموذج الأولي يكفي أن يكون QR مربعاً `.qr` مكتوباً فيه "QR" مع قائمة حقوله في تعليق؛ المنفّذ يولّده فعلياً.
البيانات وهمية: `شركة تجريبية`، `عميل-001`، `3000xxxxxx00003`، مبالغ دائرية.
